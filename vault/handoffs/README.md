# Handoff notes

One note per handoff: `handoffs/<job-id>.md` (append `-<n>` for further checkpoints of the same job).
Sections mirror `.llm-router-handoff.md`: Goal, Files touched, Diff summary, Test status,
Decisions, Next steps, Gotchas.

Link format (Obsidian wikilinks, paths relative to the vault root):
- Back to the job: `[[jobs/<job-id>]]`
- Previous handoff: `[[handoffs/<job-id>-<n-1>]]`
- Worker scorecard: `[[scorecards/<worker>]]`

Secrets must be redacted before a handoff is written.
