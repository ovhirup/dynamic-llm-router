# Reuse-Before-Build Scan: Open-Source Agent Tools for DLR (#139)

Status: complete (1 Nov 2026). Source catalog: [`slavakurilyak/awesome-ai-agents`](https://github.com/slavakurilyak/awesome-ai-agents) (MIT, `awesome-agents.json` / `.yaml`).

## 1. Selection Principles

1. **Zero hosted telemetry for code or prompts:** Never send repo diffs, prompts, or private kit content to a hosted SaaS collector.
2. **16 GB M4 RAM & zero-dependency core:** Prefer pure-Python / local-file implementations (`JSONL` / Markdown) over heavy Docker/Postgres/Neo4j stacks.
3. **Permissive open-source licenses only:** MIT or Apache-2.0, actively maintained.
